# Water Bucket Game

Simple 2D Unity game where the player moves a bucket to catch falling water drops.

## Gameplay
- Move the bucket using Left and Right arrow keys.
- Catch the falling water drop to increase score.
- If the drop falls, it respawns from the top.

## Controls
- Left Arrow → Move Left
- Right Arrow → Move Right

## Project Structure
Assets/
 ├── Scripts/        # C# game logic
 ├── Sprites/        # Game images
 ├── Prefabs/        # Reusable objects
 └── Scenes/         # Unity scene file

## Requirements
- Unity 2022.3 LTS or newer
- 2D Core Template
